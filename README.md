# ai-projects

This repository groups practical AI projects focused on text analytics, retrieval-augmented generation (RAG), and computer vision workflows.

## Projects

### FIA
Feedback Intelligence Analytics for YouTube comments, combining supervised learning, unsupervised NLP, temporal trend analysis, and generative LLM workflows.

- Project README: [FIA/README.md](FIA/README.md)

### IAG-LLM
Django web application for ingesting PDFs/URLs, generating embeddings with Ollama, and answering questions through a citation-based RAG chat.

- Project README: [IAG-LLM/README.md](IAG-LLM/README.md)

### VCD (FaceFusion)
Computer vision demo using FaceFusion in Docker to perform face swaps on image and video assets.

- Project README: [VCD/facefusion/README.md](VCD/facefusion/README.md)
